作业 1 / 第 01 题 · 单选题

强化学习中的智能体

_____ 是作出智能决策的主体，也是 RL 的学习者。其目标是最大化收到的总收益。

  1. A. 环境
  2. B. 智能体
  3. C. 策略
  4. D. 奖励
答案与解析
B. 智能体

解析

智能体（Agent）是学习与决策的主体。它观察状态，依据策略选择动作，并利用环境反馈改进决策。环境是交互对象；策略是动作选择规则；奖励是反馈信号，三者都不是题目中的学习者。

st → 选择 at → 环境返回 (rt+1, st+1)

强化学习通常追求期望长期回报，而不是让当前一步的奖励尽可能大。

Gt = rt+1 + γrt+2 + γ²rt+3 + ⋯

拓展 · 回报、价值与奖励

奖励是单步反馈；回报是一条轨迹上的累积奖励；状态价值是给定策略后、从某状态出发的期望回报。

Vπ(s) = Eπ[Gt | St = s]

一次行动可能先付出成本，再获得更大的未来收益。应使用长期价值比较动作。

作业 1 / 第 02 题 · 单选题

强化学习中的环境

与智能体交互的所有内容都称为 _____。

  1. A. 环境
  2. B. 动作
  3. C. 模型
  4. D. 策略
答案与解析
A. 环境

解析

环境（Environment）是智能体之外、与智能体交互的系统。它接收动作，产生下一状态和奖励。动作只是智能体的行为；模型是对转移和奖励规律的描述；策略是智能体的决策规则。

  • 机器人：控制程序可作为智能体，地面、障碍物以及被控制的物理机体可作为环境。
  • 下棋：下棋程序作为智能体，棋局和对手的反应作为环境的一部分。
智能体 ── 动作 at ──→ 环境
智能体 ←── 状态 st+1 与奖励 rt+1 ── 环境

拓展 · 智能体边界与可观测性

智能体与环境的边界由建模方式决定，并不必然等于机器人外壳。状态（State）与观测（Observation）也不完全相同：传感器读数可能只包含真实状态的一部分。若观测缺少决策所需信息，可以加入历史、速度等变量，或使用部分可观测模型。

作业 1 / 第 03 题 · 单选题

强化学习的核心思想

_____ 的核心思想是，智能体（AI）与环境交互，接收奖励（正面的或负面的），并根据奖励情况提升自身的决策能力，以期获得最高的累积收益。

  1. A. 启发式搜索
  2. B. 监督学习
  3. C. 深度学习
  4. D. 强化学习
答案与解析
D. 强化学习

解析

题干包含智能体、环境、奖励、决策与累积收益，描述的是强化学习（Reinforcement Learning）。智能体通过试错获得经验，再改进策略。

观察状态 → 选择动作 → 接收奖励与下一状态 → 学习 → 再次交互
π* ∈ arg maxπ Eπ[G0]

这里的期望采用给定的初始状态分布。启发式搜索用启发函数指导搜索；监督学习学习输入到标签的映射；深度学习使用多层神经网络，能够与强化学习结合形成深度强化学习。

迷宫示例：每步奖励 −0.1，撞墙额外惩罚 −1，到达终点奖励 +100。智能体通过尝试学习能够获得较高回报的路径。

拓展 · 延迟奖励与信用分配

奖励可能在许多动作之后才出现。信用分配问题就是判断之前哪些动作促成了结果。奖励设计也会影响学到的行为：若每走一步都得到正奖励，智能体可能偏好绕圈而不是到达终点。奖励应与任务目标一致。

作业 1 / 第 04 题 · 判断题

强化学习是否需要标签

强化学习的训练样本集中，需要给出“标签”数据。

  1. A. 对
  2. B. 错
答案与解析
B. 错

解析

本题为错。标准强化学习不要求为每个状态提供“正确动作”标签，而是通过奖励学习哪些行为能带来更高的长期收益。

  • 监督学习：图片 → “猫”这一标签。
  • 强化学习：状态 → 采取动作 → 观察奖励与下一状态。

奖励评价行为的结果，通常不能直接告诉智能体当前最优动作是什么。例如撞墙得到 −10，智能体还需要结合其他经验判断应该怎样走。

拓展 · 奖励不是动作标签，但 RL 可以结合监督信号

典型经验可以写为 (s, a, r, s′, done)。离线强化学习也可使用事先采集的交互数据；“不需要正确动作标签”不等于“不需要数据”。模仿学习、辅助监督任务或人类反馈可与 RL 结合，因此也不应说强化学习绝对不能使用标签。

TD 学习会构造学习目标，例如 y = r + γV(s′)。这种由经验构造的目标，不是人工标注的正确动作。终止转移通常不再加下一状态价值。

作业 1 / 第 05 题 · 单选题

ε-贪心动作选择

在 ε-贪心动作选择中，对于两个动作且 ε = 0.5 的情况，选择贪心动作的概率是多少？

  1. A. 0.25
  2. B. 0.75
  3. C. 1
  4. D. 0
答案与解析
B. 0.75

解析

题干修复：原材料中的 ε = 0. 被截断；依据你提供的解题过程恢复为 ε = 0.5。采用唯一贪心动作、探索时从所有动作中均匀抽样的标准约定。

ε-greedy 平衡探索与利用：以 1 − ε 的概率利用当前估计，选择贪心动作；以 ε 的概率从所有动作中随机选一个。探索时仍然可能抽到贪心动作。

P(贪心动作) = (1 − ε) + ε / n
= (1 − 0.5) + 0.5 / 2 = 0.5 + 0.25 = 0.75

例如 Q(s,a₁) = 10，Q(s,a₂) = 6，则 a₁ 是当前的贪心动作。但 a₂ 可能因样本不足被低估，因此需要探索。

若 ε = 0.2 且 n = 4，贪心动作概率是 0.85，每个非贪心动作的概率是 0.05，总和为 1。

拓展 · 并列最优与另一种探索约定

若 n 个动作中有 k 个并列贪心动作，且利用阶段也在这 k 个动作中均匀抽样，则每个贪心动作概率为 (1 − ε)/k + ε/n，选中任意贪心动作的总概率为 1 − ε + εk/n。

若另行规定探索时只选非贪心动作，则唯一贪心动作的概率为 1 − ε。这不是本题使用的约定。

作业 2 / 第 01 题 · 单选题

马尔可夫性

马尔可夫性是指系统的下一个状态只与 ______ 有关，而与来到当前状态的路径无关。

  1. A. 初始状态
  2. B. 当前状态
  3. C. 当前状态的前一个状态
  4. D. 终止状态
答案与解析
B. 当前状态

解析

马尔可夫性（Markov Property）表示：给定当前状态后，过去历史不再为下一状态的预测提供额外信息。当前状态应包含预测所需的信息。

P(St+1 | St, St−1, …, S0) = P(St+1 | St)

在有动作的 MDP 中，转移分布还要以当前动作为条件：

P(St+1 | St, At, 历史) = P(St+1 | St, At)

机器人位于 (3,4)，若位置和动作足以决定转移规律，那么此前从哪条路径到达 (3,4) 不再影响下一状态分布。初始状态、前一个状态和终止状态都不是该定义中所指的条件。

拓展 · “只依赖现在”不等于未来确定

马尔可夫性描述条件概率分布，并不要求转移是确定性的。相同状态与动作可以产生多个随机结果。若机器人的速度影响运动，仅用位置作为状态可能不满足马尔可夫性；加入速度后，状态表示可能更充分。

作业 2 / 第 02 题 · 单选题

折扣因子的性质

下列关于马尔可夫决策过程中的折扣因子的说法哪个是不正确的？

  1. A. 折扣因子可以大于 1
  2. B. 可以用于避免马尔可夫过程中的循环导致的无限奖励
  3. C. 折扣因子等于 0 时意味着只考虑即时奖励
  4. D. 折扣因子可以帮助获得良好的数学性质
答案与解析
A. 折扣因子可以大于 1

解析

按本课程标准折扣回报的定义，γ 通常在 [0,1] 内；无限时域折扣任务通常取 0 ≤ γ < 1，因此不正确的是 A。

Gt = Rt+1 + γRt+2 + γ²Rt+3 + ⋯
  • B：在奖励有界且 γ < 1 时，折扣可使无限循环中的累积回报有界。每步奖励 1，γ = 0.9 时，G = 1/(1 − 0.9) = 10。
  • C：γ = 0 时，Gₜ = Rₜ₊₁，只考虑即时奖励。
  • D：在标准有限 MDP、γ < 1 的条件下，Bellman 算子具有压缩性质，有助于保证唯一不动点与迭代收敛。
|Rt| ≤ Rmax ⇒ |Gt| ≤ Rmax / (1 − γ)

γ 越大，未来奖励的权重越大。若 γ > 1，远期权重会增长；例如每步奖励 1 的无限过程将发散。

拓展 · γ = 1 的边界条件

有限时域任务可以取 γ = 1。对于随机长度的回合任务，即使最终几乎必然终止，也仍需适当的可积性条件才能保证期望回报有限，例如奖励有界且期望回合长度有限。“会终止”本身不是所有收敛结论的充分条件。

作业 2 / 第 03 题 · 判断题

状态转移矩阵

马尔可夫过程中的状态转移矩阵每一行的和可以不为 1。

  1. A. 对
  2. B. 错
答案与解析
B. 错

解析

采用行表示当前状态、列表示下一状态的约定，完整状态空间上的转移矩阵每行是一个概率分布，因此必须非负且和为 1。

Pij = P(St+1 = j | St = i)
0 ≤ Pij ≤ 1，　∑j=1n Pij = 1
合法转移矩阵示例
当前状态到 S₁到 S₂到 S₃行和
S₁0.20.50.31
S₂0.10.70.21
S₃0.40.10.51

第一列之和为 0.7，第二列为 1.3，第三列为 1。列和一般不必等于 1。

拓展 · 终止状态与次随机矩阵

把终止状态纳入完整矩阵并设为吸收态，可令 P(终止→终止) = 1。如果只保留非终止状态，则得到子矩阵，每行和可能小于 1；缺少的概率对应进入终止状态。这不反驳完整转移矩阵的行和规则。另有文献使用列随机约定，阅读时应先看下标定义。

作业 2 / 第 04 题 · 单选题

直接求解状态价值的复杂度

对于含有 n 个状态的马尔可夫奖励过程，其状态价值可以通过直接求解方程组获得，计算复杂度为？

  1. A. O(n)
  2. B. O(n²)
  3. C. O(n³)
  4. D. O(n⁴)
答案与解析
C. O(n³)

解析

马尔可夫奖励过程（MRP）的 Bellman 方程把当前价值拆为一步期望奖励与折扣后的下一状态价值。

V = R + γPV
(I − γP)V = R
V = (I − γP)−1R

V 是 n 维价值向量，R 是一步期望奖励向量，P 是 n × n 转移矩阵，I 是单位矩阵。经典稠密高斯消元或 LU 分解的时间复杂度为 O(n³)，所以选 C。

n² 是矩阵元素数量，但消元还需逐轮更新子矩阵。累计运算量与 1² + 2² + ⋯ + n² 同阶，因此是 O(n³)。

拓展 · 求解线性系统，而不是显式求逆

公式中的逆矩阵主要用于理论表达。实现时通常直接求解 (I − γP)V = R，以避免显式求逆的额外开销。对于行随机 P 和 γ < 1，该矩阵可逆；γ = 1 时不能无条件套用逆矩阵公式。

稠密存储需要 O(n²) 空间。稀疏或特殊结构可能降低成本，O(n³) 指经典一般稠密直接法。迭代评估使用 Vₖ₊₁ = R + γPVₖ；稠密一次更新约 O(n²)，总成本还取决于达到精度需要多少次迭代。大型问题也可采用 MC、TD 或函数近似。

作业 2 / 第 05 题 · 判断题

最优策略是否唯一

马尔可夫决策过程中的最优策略是唯一的。

  1. A. 对
  2. B. 错
答案与解析
B. 错

解析

本题为错。不同策略可以实现相同的最优价值。考虑两个动作都立即获得 10 并终止：

Q*(s,A) = 10，　Q*(s,B) = 10

始终选 A 与始终选 B 是两个不同的确定性策略，但都达到 V*(s) = 10。以 0.3 的概率选 A、0.7 的概率选 B，也获得同样价值。

V*(s) = maxπ Vπ(s)
π*(s) ∈ arg maxa Q*(s,a)

arg max 返回取得最大值的动作集合，而 max 返回最大值本身。多个动作可以共享一个最大值。

拓展 · 唯一价值与多种最优策略

在标准有限状态、有限动作、奖励有界且 γ < 1 的 MDP 中，最优价值函数是唯一的，且存在确定性平稳最优策略；但该策略未必唯一。若每个状态只在达到 Q* 最大值的动作上分配概率，可得到随机最优策略。

注意，“两个动作价值相同”还不够，它们必须都达到最大值。例如价值为 5、5、10 的三个动作中，前两个虽然相等，却不是最优动作。

策略迭代的基本步骤

策略迭代包括哪些步骤？

  1. A. 策略评估
  2. B. 策略提升
  3. C. 价值迭代
  4. D. 动态规划
答案与解析
A. 策略评估；B. 策略提升

解析

策略迭代（Policy Iteration）的核心是先评价当前策略，再根据评价结果改进策略。因此选 A、B。

当前策略 π → 策略评估 → Vπ → 策略提升 → 新策略 π′ → 继续迭代

① 策略评估（Policy Evaluation）

固定策略 π，计算一直按照该策略行动时，每个状态的期望长期回报。状态价值满足 Bellman 期望方程：

Vπ(s) = ∑a π(a|s) ∑s′,r p(s′,r|s,a)[r + γVπ(s′)]

可以直接求解线性方程组，也可以反复进行期望更新，将价值评估到足够精确。

② 策略提升（Policy Improvement）

对每个状态做一步前瞻，然后选择当前策略价值下最好的动作：

Qπ(s,a) = ∑s′,r p(s′,r|s,a)[r + γVπ(s′)]
π′(s) ∈ arg maxa Qπ(s,a)

这里先执行候选动作 a，之后按旧策略 π 行动。对所有状态进行贪心提升后，再重新评估新策略。价值迭代是另一种算法；动态规划是一类方法，都不是策略迭代的具体步骤。

拓展 · 策略提升定理与稳定的并列处理

在有限折扣 MDP、精确策略评估等标准条件下，贪心提升使 Vπ′(s) ≥ Vπ(s)。若策略对自身价值已经贪心，则满足 Bellman 最优方程，策略最优。

实现时若多个动作并列最优，优先保留旧动作，或使用固定的并列处理规则，避免在同样好的策略之间反复切换。只有近似评估时，“策略没变”不应被无条件视为精确最优的证明。

动态规划的适用条件

动态规划适用于什么样的问题？

  1. A. 具有最优子结构和重叠子问题的问题
  2. B. 具有子问题但不一定有最优子结构的问题
  3. C. 只有具有最优子结构但没有重叠子问题的问题
  4. D. 只有具有重叠子问题但不具有最优子结构的问题
答案与解析
A. 具有最优子结构和重叠子问题的问题

解析

按经典优化问题的教学表述，最合适的是 A：最优子结构与重叠子问题。

最优子结构（Optimal Substructure）

原问题的最优解可以由适当子问题的最优解构成。例如在最短路径存在的标准问题中，若从 A 到 C 的最短路径经过 B，那么其中 A 到 B 的子路径也必须最短；否则替换成更短子路径，就能改进整条路径。

重叠子问题（Overlapping Subproblems）

相同子问题反复出现，存储计算结果能避免重复工作。Fibonacci 递推 F(n)=F(n−1)+F(n−2) 中，计算 F(5) 会多次调用 F(3)、F(2)。记忆化或自底向上计算只需求每个子问题一次。

拆解问题 → 求解子问题 → 保存结果 → 复用结果

B 仅有子问题，不足以保证最优解能正确组合；C 缺少重叠，缓存优势不明显；D 只有重复计算，也不足以保证最优解的组合正确。

拓展 · MDP 为什么适合动态规划？

Bellman 方程将当前决策分解为一步奖励与后继状态价值，体现最优子结构。不同路径与动作可能到达相同状态，因此同一个状态价值可被重复使用。

“两个特征”是本题的典型优化问题判据，并非对所有 DP 的绝对定义。计数等非优化问题也能用 DP；Fibonacci 是展示重复子问题的例子，本身没有“最优解”。没有重叠时递推仍可能成立，只是存表未必带来额外收益。

作业 3 / 第 05 题 · 多选题

异步动态规划

下列关于异步动态规划的说法中，哪些是正确的？

  1. A. 异步动态规划需要同时更新所有状态的价值
  2. B. 异步动态规划不能减少计算复杂度
  3. C. 就地动态规划、优先级扫描、实时动态规划都属于异步动态规划
  4. D. 优先级扫描可利用贝尔曼误差的大小指导状态的选择
答案与解析
C. 就地动态规划、优先级扫描、实时动态规划都属于异步动态规划；D. 优先级扫描可利用贝尔曼误差的大小指导状态的选择

解析

异步动态规划（Asynchronous DP）允许按需选择状态更新，而不是每轮都从同一份旧价值表计算全体状态的新值。因此答案为 C、D。

  • A 错：异步更新可以采用 S₂ → S₄ → S₁ → S₂ → S₅ 等顺序，不要求一轮覆盖全体状态。
  • B 错：合理的调度能够减少不必要的更新和实际计算量，但不保证在每个问题上都降低最坏情况的渐近复杂度。
  • C 对：就地动态规划、优先级扫描和实时动态规划都是典型异步方法。
  • D 对：可用 Bellman 残差的大小决定优先更新哪些状态。

三种典型方法

  • 就地 DP（In-place DP）：只保留一份价值表，一个状态更新后，其新值可立即参与后续状态的更新。
  • 优先级扫描（Prioritized Sweeping）：优先处理残差较大或受价值变化影响较大的状态；更新后，利用前驱关系把影响继续传播。
  • 实时 DP（Real-Time DP）：沿模拟或实际交互轨迹，集中更新访问到的状态，减少对无关区域的计算。

用 Bellman 残差设置优先级

δ(s) = | maxa [R(s,a) + γ∑s′P(s′|s,a)V(s′)] − V(s) |

此处 R(s,a) 是一步期望奖励，δ 已取绝对值，因此非负。它比较当前价值与模型计算出的更新目标；差距越大，通常越值得优先更新。

较大残差 → 较高优先级 → 更新价值 → 重新评估相关前驱的优先级

拓展 · 同步不是并行；异步也需要覆盖条件

同步与异步的区别在于更新读取哪一版价值、选择哪些状态，并不等于多线程与单线程之分。同步更新可以顺序计算，但所有状态都读取旧表；就地更新则能读取本轮刚得到的新值。

在有限折扣 MDP 中，用最新可用价值做异步最优更新，若每个状态都被无限次更新，可保证标准收敛结论。若长期忽略某些状态，就不能无条件保证全状态最优。实时 DP 只集中于访问区域时，保证范围还取决于探索、初始化及任务假设。

模型下的 Bellman 残差也不同于单条经验的 TD 误差：后者含采样噪声，不能简单视为同一个量。

Gt = ∑k=0T−t−1 γkRt+k+1

  • C：需加条件。 抽样避免了枚举全部后继转移，可能减少计算，但样本方差、回合长度和采样成本都影响效率，不能保证比 DP 更快。

拓展 · 完整回报、自举与持续任务

MC 使用完整回报作为目标，不自举；TD 用 Rₜ₊₁ + γV(Sₜ₊₁) 作为目标，依赖已有价值估计，可以不等回合结束就更新。

无限折扣回报在数学上可能存在，但有限计算无法直接观察其无限尾部。人为截断会遗漏尾部；若追加估计价值，就引入了自举。应区分这些变体与本题的经典完整回合 MC。非马尔可夫观测下，估计还可能取决于历史分布；加入历史、记忆或信念状态有助于决策。

作业 4 / 第 02 题 · 判断题

蒙特卡洛策略迭代是否有模型

蒙特卡洛策略迭代是一种有模型强化学习方法。

  1. A. 对
  2. B. 错
答案与解析
B. 错

解析

答案为 B，错。经典蒙特卡洛策略迭代属于无模型（model-free）方法：它从状态、动作、奖励序列估计价值，不要求知道完整的转移概率 P(s′|s,a) 与奖励模型。

按当前策略采集完整回合 → 用回报估计 Qπ(s,a) → 改进策略 → 继续采样

它保留了作业 3 中“评估 + 提升”的结构，但把使用已知模型的精确或迭代评估，换成了基于采样回报的估计。为避免过早停止探索，通常采用探索性起步或 ε-soft / ε-greedy 策略。

拓展 · 为什么无模型控制常估计 Q？

只知道 V(s)，一般还需要转移模型才能比较执行不同动作后的期望结果。直接估计 Q(s,a)，则可以通过比较动作价值来改进策略，无须显式计算转移分布。

从模拟器取得经验，不会自动把算法变成需要显式环境模型的 DP。模拟器可以只提供样本；如果整体系统先学习模型，再用模型生成经验规划，则整个系统又可属于基于模型的方法。应区分经验来源与学习算法依赖的信息。

N(s) ← N(s) + 1

ε-贪心策略的实现

ε-贪心策略是强化学习中一种重要的探索与利用平衡策略，其中 ε 是探索概率。以下哪个选项描述了 ε-贪心策略的实现方式？

  1. A. 在每个状态下，随机选择一个动作执行
  2. B. 按照预先定义好的动作顺序执行
  3. C. 根据当前状态值函数选择动作
  4. D. 以概率 ε 随机选择动作，以概率 1−ε 选择当前最优动作
答案与解析
D. 以概率 ε 随机选择动作，以概率 1−ε 选择当前最优动作

解析

答案为 D。标准 ε-greedy 以概率 ε 从所有可选动作中均匀抽样，以概率 1−ε 选择当前估计价值最大的动作。前者探索，后者利用。这里“当前最优”指当前估计下的贪心动作，不保证是真实最优动作。

a* ∈ arg maxa Q(s,a)
唯一贪心动作：π(a*|s) = 1−ε+ε/n
任一非贪心动作：π(a|s) = ε/n

随机探索仍然可能选中贪心动作，因此探索概率不是“选择非贪心动作的总概率”。例如 ε = 0.2、n = 4 时，贪心动作概率 0.85，每个非贪心动作概率 0.05；这与作业 1 第 5 题的计算规则一致。

  • A：始终随机，未体现一般 ε-greedy 的利用部分，仅对应 ε = 1 的特殊情况。
  • B：固定顺序不体现按价值利用与随机探索的混合。
  • C：未体现 ε 探索；而且单个状态价值 V(s) 本身不能区分该状态下的动作，一般需要 Q(s,a) 或结合模型做一步前瞻。

拓展 · 固定 ε、ε-soft 与 GLIE

ε > 0 时，每个动作至少获得 ε/n 的选择概率，属于 ε-soft 策略。这能保留动作探索机会，但不能单凭固定 ε 就保证所有状态都被充分访问。

固定 ε 的行为策略持续探索，一般不等于完全贪心最优策略。若希望逐渐转向贪心，同时仍保证充分探索，可研究 GLIE（无限探索、极限贪心）条件；仅写“ε 随时间减小”并不足以证明收敛，下降过快可能探索不足。若多个动作并列最优，还应明确并列动作的选择规则。

答案与解析
C. 时序差分方法不需要知道完整轨迹信息

解析

答案为 C。一步时序差分学习 TD(0) 观察到一次状态转移及奖励，就能结合下一状态的当前价值估计进行更新，无需等待完整回合结束。

V(St) ← V(St) + α[Rt+1 + γV(St+1) − V(St)]
TD 目标 yt = Rt+1 + γV(St+1)
TD 误差 δt = yt − V(St)
  • A 错：典型比较中，MC 的完整回报累积了整条后续轨迹的随机性；一步 TD 使用较短的采样目标，通常方差较低，但会受到自举估计误差影响。不能把这当作所有环境下都成立的严格方差大小定理。

拓展 · 自举：用估计更新估计

TD 目标中的 V(Sₜ₊₁) 是已有估计，因此称为自举（bootstrapping）。MC 的目标是完整采样回报 Gₜ，不使用后继状态的价值估计。

“不需要完整轨迹”不等于“不需要经验”或“任意学习率都收敛”。表格型 TD 的收敛仍需要适当的任务条件、状态访问和步长安排；使用函数近似时还须额外分析稳定性。

作业 5 / 第 02 题 · 判断题

同策略与异策略

同策略与异策略的区别在于目标策略与行为策略是否一致。

  1. A. 对
  2. B. 错
答案与解析
A. 对

解析

答案为 A，对。行为策略（behavior policy，常记 b）负责产生数据；目标策略（target policy，常记 π）是被评估或改进的策略。

  • 同策略（on-policy）：学习当前用于产生经验的策略。经典 SARSA 通常用当前 ε-greedy 策略采样，也在目标中使用该策略选出的下一动作。
  • 异策略（off-policy）：可用一种策略的数据学习另一种策略。Q-learning 可用带探索的行为策略采样，却以对 Q 的贪心选择构造目标。
行为策略 b：怎样获得数据？
目标策略 π：这些更新在学习谁？

这一区别不取决于数据来自真实环境还是模拟器，也不等同于“是否随机”“是否在线”。

拓展 · 同策略也会变化；异策略也可以暂时相同

控制过程中，on-policy 的策略可以随着价值估计改变；“同”指采样与学习所针对的策略一致，不是整个训练永远固定一个策略。Off-policy 方法允许两者不同，并不要求它们在每个时刻、每个状态都不同。

从行为策略的数据评估目标策略时，需要数据覆盖目标策略会选择的动作。重要性采样是一种校正分布差异的方式，但并非所有异策略算法都显式使用重要性权重，例如标准一步 Q-learning。

Q-learning 的基本性质

下列关于 Q-Learning 的说法中，哪一个是正确的？

  1. A. Q-Learning 算法是一种基于模型的强化学习算法。
  2. B. Q-Learning 算法可以用于解决连续状态和动作空间的问题。
  3. C. Q-Learning 算法使用 ε-贪心策略来平衡探索和利用。
  4. D. Q-Learning 算法使用蒙特卡罗方法来更新 Q 值。
答案与解析
C. Q-Learning 算法使用 ε-贪心策略来平衡探索和利用。

解析

建议选 C，按经典表格型 Q-learning 与常见 ε-greedy 实现理解。ε-greedy 是常用选择，并不是 Q-learning 定义强制规定的唯一行为策略。

Q-learning 直接从转移经验更新动作价值，使用下一状态的最大估计动作价值进行自举：

Q(St,At) ← Q(St,At) + α[Rt+1 + γ maxa Q(St+1,a) − Q(St,At)]
  • A 错：标准 Q-learning 是无模型 TD 控制算法，不需要显式转移概率。
  • B 不符合本题的标准表格语境：普通 Q 表不能直接枚举无限的连续状态与动作。连续问题需要离散化、函数近似或其他扩展，不能不加条件地套用表格算法。
  • C 对：常用 ε-greedy 行为策略保留随机探索，同时利用当前 Q 值选择贪心动作。
  • D 错：其标准一步更新是 TD 更新，不需要等待完整回报，因而不是蒙特卡洛更新。

拓展 · 连续状态与连续动作是两种不同的难点

函数近似可以让 Q(s,a) 接收连续状态，例如常见 DQN 处理连续或高维状态但使用离散动作。连续动作还需要计算 maxₐ Q(s′,a)，往往涉及额外优化或策略网络。

所以不能说所有 Q-learning 扩展都无法处理连续空间，也不能把扩展能力直接归给普通 Q 表。探索可用 ε-greedy 或其他满足任务需要的方法；收敛分析还需要充分访问和合适步长等条件。

Q-learning 的后继状态价值

Q-Learning 中，TD 目标的后继状态的价值是如何计算的？

  1. A. 所有动作的平均价值
  2. B. 最优动作的价值
  3. C. 最差动作的价值
  4. D. 完整采样的实际奖励
答案与解析
B. 最优动作的价值

解析

答案为 B。Q-learning 取下一状态所有可选动作的 Q 估计最大值。这里“最优动作”指当前估计下的贪心动作，并不是已经知道真实的最优动作。

yt = Rt+1 + γ maxa Q(St+1,a)

假设下一状态的两个动作价值估计为 5 和 2，即时奖励为 1，γ = 0.9，则后继价值取 5，TD 目标为 1 + 0.9 × 5 = 5.5。若当前 Q = 3，α = 0.1，更新后为 3 + 0.1 × (5.5 − 3) = 3.25。

若下一状态是真正的终止状态，不再计算后续收益，目标取即时奖励 Rₜ₊₁。若只是外部时间限制导致采样截断、任务本身尚未终止，是否继续自举需依据任务定义，不能混为一谈。

对带噪声的多个 Q 估计取最大值可能产生高估，即最大化偏差。Double Q-learning 的思路是分开动作选择与价值评估，以减少这种偏差。

解析

这说明 SARSA 的目标会计入当前探索策略可能采取的动作；若下一动作恰好也是贪心动作，两种算法在该步的目标可能相同。终止时不需要再选择下一动作，目标直接取奖励。

TD(0) 目标：Rt+1 + γV(St+1)

V(St) ← V(St) + α[Gt:t+1 − V(St)]

真正终止时，后继状态价值取 0。TD(0) 中的 0 指 λ = 0，不是“零步更新”：它仍然使用一次转移及其奖励。

  • A、B：Q-learning 与 SARSA 是动作价值控制算法，不是本题状态价值预测 TD(λ) 在 λ = 0 时的名称。
  • C：蒙特卡洛使用完整采样回报，对应本题 λ = 1 的前向视角端点。
  • D：保留一步 TD 目标，正确。

拓展 · 从资格迹看 λ = 0

在表格型、累积资格迹（accumulating traces）的后向实现中，回合开始令 e₋₁(s)=0，每步使用：

et(s) = γλet−1(s) + 𝟙{s = St}
δt = Rt+1 + γV(St+1) − V(St)
V(s) ← V(s) + αδtet(s)

𝟙 是指示函数。当 λ = 0 时，旧资格迹全部消失，只有当前状态的迹为 1，所以只更新当前状态，正好得到 TD(0)。

作业 6 / 第 02 题 · 单选题

λ = 1：完整回报端点

在 TD(λ) 算法中，λ 取值为 1 时，算法是什么？

  1. A. 蒙特卡洛方法
  2. B. SARSA(λ)
  3. C. Q-learning
  4. D. TD(0)
答案与解析
A. 蒙特卡洛方法

解析

答案为 A，蒙特卡洛方法。按有限回合的经典前向视角，λ = 1 时，λ-return 完全由回合终止前的实际回报构成，不再依赖中途的价值自举。

设终止时刻为 T，剩余步数 m = T−t ≥ 1。令 Gₜ:ₜ₊ₙ 为 n 步回报，Gₜ 为完整回报。有限回合的 λ-return 为：

Gtλ = (1−λ) ∑n=1m−1 λn−1Gt:t+n + λm−1Gt

λ = 1 时，所有未到终点的短步长权重为 0，完整回报的权重为 1。若只剩一步，求和为空，目标直接是完整的一步回报。端点的零次幂权重按 1 处理。

Gtλ=1 = Gt = ∑k=0m−1 γkRt+k+1

因此常用记忆是“λ = 0 对应 TD(0)，λ = 1 对应 MC”。SARSA(λ) 是带迹的动作价值控制方法，不能由预测算法单靠改变 λ 就变成；Q-learning 也不是该端点。

拓展 · 目标等价不等于所有在线实现逐步完全一致

上述结论针对有限完整回合的前向 λ-return。回合内冻结价值、累积更新的离线条件下，经典累积迹的前后向视角具有对应关系。若传统在线 TD(λ) 在回合中不断改变价值估计，就不能无条件宣称它在每一步都与普通 MC 完全相同。

True Online TD(λ) 在其表格或线性函数近似设定下，建立了与特定在线前向视角的精确对应。持续任务中没有有限终点，也不能直接照搬这里的完整回合推导。参考：van Seijen 与 Sutton，True Online TD(λ)。

λ 的取值范围

TD(λ) 算法中的 λ 参数的取值范围是：

  1. A. [0,1]
  2. B. (0,1]
  3. C. [0,1)
  4. D. (0,1)
答案与解析
A. [0,1]

解析

答案为 A，[0,1]。标准 TD(λ) 同时包含 λ = 0 与 λ = 1 两个端点，另外三个选项分别排除了至少一个端点。

0 ≤ λ ≤ 1
  • λ = 0：仅使用一步 TD 目标。
  • 0 < λ < 1：混合不同步长的目标。
  • λ = 1：有限回合前向目标是完整 MC 回报。

以剩余 3 步的回合为例，1 步、2 步、完整 3 步目标的权重分别是 1−λ、(1−λ)λ、λ²。它们非负且总和为 1。取 λ = 0.5，得到 0.5、0.25、0.25。

拓展 · 不要混淆 λ、γ 与 α

三个参数分别控制什么？
参数含义作用
λ迹衰减 / 回报混合参数控制不同备份长度的权重
γ折扣因子控制未来奖励的折扣
α学习率控制每次参数更新的幅度

在累积资格迹中，旧迹的单步衰减系数是 γλ，而不是仅 λ。因此即使 λ = 1，只要 γ < 1，未再次访问状态的旧迹仍会衰减。λ 较大通常更偏重长回报，但不保证误差一定更小；表现取决于采样方差、自举误差、步长与任务。

作业 6 / 第 04 题 · 判断题

TD(λ) 与 n-step TD

TD(λ) 和 n-step TD 是同一个算法的不同名称。

  1. A. 对
  2. B. 错
答案与解析
B. 错

解析

答案为 B，错。二者有关联，但不是同一个算法的别名。固定 n-step TD 选择一个步长 n；TD(λ) 的前向视角将多个步长回报按 λ 加权混合。

n 步目标（t+n < T）：
Gt:t+n = ∑k=0n−1 γkRt+k+1 + γnV(St+n)

若在 n 步之内终止，则只累加到终止，不再加终止后的价值。TD(λ) 则使用第 2 题给出的 λ-return，而不是单独选取一个固定 n。

两种多步学习方式
维度固定 n-step TDTD(λ)
主要参数步数 n混合系数 λ
前向目标一个指定步长的回报多个步长回报的加权组合
典型实现保存所需的近期转移使用资格迹向过去分配当前 TD 误差
共同端点n = 1 是一步 TDλ = 0 是一步 TD

例如剩余 3 步，三个目标分别为 2、4、8。固定 2-step TD 的目标是 4；λ = 0.5 的前向混合目标为 0.5×2 + 0.25×4 + 0.25×8 = 4。这次碰巧相等，并不说明算法相同；若完整回报改成 12，混合目标就变为 5，而固定 2-step 目标仍是 4。

拓展 · 前向视角与后向视角

前向视角从当前时刻向未来看，描述“用什么目标学习”；后向视角利用资格迹，将当前 TD 误差分配给近期访问过的状态，描述一种可在线执行的机制。

因此不能把“TD(λ) 融合多步信息”误解为“它就是某个固定 n-step TD”。λ 接近 1 会提高较长回报的相对权重，但不存在对任意任务都能把一个 λ 精确替换成一个固定 n 的通用公式。

欠拟合的含义

在函数拟合中，欠拟合指：

  1. A. 模型过于复杂，导致在训练集上表现很好，但在测试集上表现较差
  2. B. 模型无法捕捉到数据中的复杂关系，表现出过于简单的形式
  3. C. 模型的参数数量过多，导致训练困难
  4. D. 模型的损失函数出现了局部最优解
答案与解析
B. 模型无法捕捉到数据中的复杂关系，表现出过于简单的形式

解析

答案为 B。欠拟合（underfitting）指模型未能充分学习数据的规律，通常连训练数据都拟合不好。例如真实关系为明显的曲线，却只能用直线表达，就可能出现欠拟合。

  • A 描述过拟合：训练集表现好，但泛化到新数据较差。
  • B 描述模型表达过于简单、未捕获复杂关系，符合欠拟合。
  • C 是参数规模与优化难度的问题，不是欠拟合的定义。
  • D 是优化问题；局部最优与欠拟合并不是同义词。

拓展 · 表达能力、优化与泛化要分开判断

训练误差较高时，原因可能是模型容量不足、特征缺少信息、正则化过强或训练未充分收敛。应先检查训练与验证误差，再决定增加表达能力、改进特征或调整优化过程。

训练误差低而验证误差明显高，更像过拟合。增大网络并不保证改善效果；验证集也应与实际应用场景相匹配，避免数据泄漏。

作业 7 / 第 02 题 · 单选题

激活函数的作用

在神经网络中，激活函数的作用是什么？

  1. A. 进行数据预处理
  2. B. 约束权重参数的范围
  3. C. 增加非线性
  4. D. 减少过拟合
答案与解析
C. 增加非线性

解析

答案为 C。非线性激活函数使多层网络能够表达复杂的非线性映射。若每一层都只有仿射变换，多层复合仍可合并成一个仿射变换。

W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)

加入 ReLU、tanh 等非线性函数后，一般就不能再这样合并。数据预处理、权重约束和减少过拟合分别有其他专门方法，不是激活函数在本题中的主要作用。

拓展 · 价值网络的输出层常采用线性输出

隐藏层需要非线性，并不意味着输出层也必须用非线性。价值可能为负，也可能大于 1；若没有额外的价值范围设计，输出层常采用线性输出。盲目使用 sigmoid 会把预测限制在 (0,1)。

例如 ReLU(x)=max(0,x)，适合许多隐藏层，但也可能产生长期不激活的单元。激活函数的选择会影响梯度传播，不能把它当作自动消除过拟合的机制。

  2. B. 用于描述动作的特征
  3. C. 用于描述状态或动作的价值
  4. D. 用于描述状态转移的概率
答案与解析
C. 用于描述状态或动作的价值

解析

答案为 C。价值函数衡量从某个状态或状态—动作对出发，按指定策略继续行动时能够获得的期望回报，或衡量最优策略下的期望回报。

Vπ(s) = Eπ[Gₜ | Sₜ=s]
Qπ(s,a) = Eπ[Gₜ | Sₜ=s, Aₜ=a]

状态与动作的特征是输入表示，转移概率 P(s′|s,a) 描述环境动力学；它们与价值函数不是同一个对象。题目中“动作的价值”更准确地指某状态下执行该动作的长期价值。

拓展 · 奖励、价值与策略的关系

奖励是一步反馈，价值考虑未来累积结果，策略决定怎样选动作。当前奖励高的动作未必长期价值高。对于固定策略，价值依赖该策略；最优价值则对可选策略取最优。

价值函数近似用共享参数替代逐状态查表，可在相似状态之间泛化。但一个参数更新也可能同时改变多个状态的预测，因而既带来样本利用优势，也引入相互干扰。

学习率过大的影响

随机梯度下降中，学习率过大会导致什么？

  1. A. 模型过拟合
  2. B. 算法不稳定
  3. C. 收敛速度快
  4. D. 模型欠拟合
答案与解析
B. 算法不稳定

解析

答案为 B。学习率过大时，一次更新可能跨过合适的低损失区域，造成震荡甚至发散，尤其在梯度噪声或曲率较大时。不能据此保证收敛更快。

θₖ₊₁ = θₖ − α∇L(θₖ)

考虑简单损失 L(w)=w²/2，其梯度为 w，更新变为 wₖ₊₁=(1−α)wₖ。当 α=0.5 时，w 每次减半；α=2 时，非零 w 在正负之间振荡而不衰减；α=3 时，绝对值每次加倍。这个例子说明大步长会破坏稳定性。

拓展 · 稳定范围取决于问题尺度

上例 0<α<2 的收敛范围只适用于该特定二次损失，不能当作所有网络的通用学习率范围。输入尺度、损失曲率、批量大小和优化器都会影响可用步长。

过拟合与欠拟合描述拟合及泛化表现；“学习率过大”的直接问题是优化不稳定，而不是必然属于其中某一种。可以结合损失曲线检查震荡，再调整学习率或梯度尺度。

学习率是什么

随机梯度下降中的学习率是什么？

  1. A. 更新步长
  2. B. 损失函数
  3. C. 正则化项
  4. D. 训练样本数量
答案与解析
A. 更新步长

解析

答案为 A。学习率 α 控制沿负梯度方向更新参数的尺度。损失函数决定优化目标，正则化项可以作为损失的一部分，样本数量则属于数据规模。

θ ← θ − αĝ
实际参数变化 Δθ = −αĝ

例如当前参数 w=2，梯度估计 ĝ=3，α=0.1，则更新后 w=2−0.1×3=1.7。相同梯度下，学习率越大，更新幅度越大。

拓展 · “步长”不等于固定的移动距离

实际更新距离为 α‖ĝ‖，还取决于梯度大小；学习率本身不是每次固定走多远。SGD 用样本或小批量梯度估计整体梯度，因此每一步方向可能带噪声。

学习率可以固定、按计划衰减或由优化器进行适应性调整。α 与强化学习中的折扣因子 γ、迹参数 λ 控制不同的事情，不应混淆。

作业 7 / 第 07 题 · 单选题

梯度下降的步骤顺序

梯度下降算法的正确步骤是什么？
a. 计算预测值和真实值之间的误差
b. 重复迭代，直至得到网络权重的最佳值
c. 把输入传入网络，得到输出值
d. 用随机值初始化权重和偏差
e. 对每一个产生误差的神经元，调整相应的（权重）值以减小误差

  1. A. abcde
  2. B. edcba
  3. C. cbaed
  4. D. dcaeb
答案与解析
D. dcaeb

解析

答案为 D，d → c → a → e → b。先初始化参数，再前向计算预测，计算损失，通过反向传播求梯度并更新参数，然后重复前向、损失计算与更新过程。

d 初始化 → c 前向传播 → a 计算误差 / 损失 → e 求梯度并更新 → b 重复迭代

没有先得到输出就不能比较预测与目标；没有误差及梯度就无法进行有依据的参数更新。初始化通常只做一次，不是在每轮训练时重新随机化。

拓展 · 原题的教学简写与实际实现

e 的准确含义是利用链式法则计算损失对可训练参数的梯度，再更新权重及偏置，并不是给每个神经元独立指定一个“正确输出”。反向传播负责计算梯度，梯度下降负责用梯度更新参数。

d 是典型初始化描述：常对权重采用合适的随机初始化以打破对称，偏置可以初始化为 0，不要求所有偏置都随机。b 中“最佳值”也不是全局最优保证；实际按验证表现、迭代预算或收敛判据停止。

价值函数近似中最常用的损失函数是？

  2. B. 平均绝对误差损失

答案为 C。原选项写“均方差损失函数”，此处按通常教材含义解释为均方误差损失 MSE。价值预测是数值回归，经常用预测与回报目标之间的平方误差训练。

L(θ) = (1/N) ∑i=1N [yᵢ − V̂(sᵢ;θ)]²

例如预测为 2、4，目标为 3、2，则 MSE=[(3−2)²+(2−4)²]/2=2.5。交叉熵与 0-1 损失通常用于分类；平均绝对误差也可用于回归，但不是本题预期的经典平方误差形式。

拓展 · MSE、半平方误差与 Huber 损失

推导中也常用 L=(y−V̂)²/2，其中 1/2 消去求导时的系数 2，不改变同一固定数据问题的最优解，但在固定学习率下会改变梯度尺度。MSE 是相对目标的误差平方均值，不是预测值自身的方差。

平方损失对大误差较敏感，实践中也会用 Huber 损失减弱极端误差的影响。因此“常用 MSE”不等于“只能用 MSE”。损失形式与目标来源是两回事：MC 与 TD 都能采用平方损失，但目标不同。

MC 使用什么学习目标

要进行梯度下降需要一个目标值，蒙特卡洛方法使用了 TD 目标作为这个目标值。

  1. A. 对
  2. B. 错
答案与解析
B. 错

解析

答案为 B，错。本题讨论价值回归时，经典蒙特卡洛方法使用完整采样回报 Gₜ 作为目标；一步 TD 使用即时奖励与后继价值估计构成的自举目标。

MC：yₜ = Gₜ = Rₜ₊₁ + γRₜ₊₂ + ⋯
TD(0)：yₜ = Rₜ₊₁ + γV̂(Sₜ₊₁;θ)

例如 γ=0.9，后续奖励依次为 1、2 并终止，MC 的目标是 1+0.9×2=2.8。若当前网络估计下一状态价值为 5，TD 目标为 1+0.9×5=5.5。二者可能不同，因为 TD 使用了尚不准确的价值估计。

拓展 · 半梯度与目标值的语境

对单样本半平方损失，若把目标 y 视为固定值，更新为：

θ ← θ + α[y − V̂(Sₜ;θ)]∇θV̂(Sₜ;θ)

MC 的已观测回报不依赖价值网络参数。经典半梯度 TD 则在构造目标后，不通过目标中的后继价值反向传播；这与对目标和预测两端都求导不同。真正终止时，TD 目标不再包含未来价值。

原题前半句“梯度下降需要一个目标值”应限于此处的监督式价值拟合。一般梯度下降只需要可优化的目标函数，并不一定需要每个样本的标注目标值。参考：价值函数近似中的 MC 与半梯度 TD。
